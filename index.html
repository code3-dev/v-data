نکته مهم برای کاربران ویندوز

اگر هنگام نصب یا اجرای CCloud در ویندوز با خطا مواجه شدید، لطفاً Microsoft Visual C++ Redistributable 2015-2022 را نصب کرده و سپس دوباره نصب یا اجرای CCloud را امتحان کنید.

می‌توانید آن را از وب‌سایت رسمی مایکروسافت دانلود کنید: Microsoft Visual C++ Redistributable

راهنمای نصب لینوکس
